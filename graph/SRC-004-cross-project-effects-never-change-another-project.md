# SRC-004: Cross-project effects never change another project

Anything crossing a project boundary (shared people, shared milestones) never changes another project. Both people and milestones can be shared across projects, and neither ever changes another project's plan automatically.

As received, the want behind it: never change someone else's project without their approval ("That would mean changing someone else project without their approval"). Extending this to shared milestones was the drafting agent's addition.
