# SRC-285: The Kanban board can be searched by task title

The Kanban board has a search box that shows only the cards whose title matches the text typed.

As received, in the design session of 2026-11-23, recorded in issue #256 (the UI/UX review of the demo deployment). Asked, about item 14 ("The board has no search or filter"), "What should it get?", with the options "Title search" ("A text box that hides cards whose title does not match."), "Search + filters", "Saved-view filters" and "None", the owner chose "Title search".

Not stated: whether the search also applies to a Kanban saved view covering several projects.
