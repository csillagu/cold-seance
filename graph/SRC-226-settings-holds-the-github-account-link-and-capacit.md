# SRC-226: Settings holds the GitHub account link and capacity and absences

Settings, brought up by clicking the signed-in person ([SRC-221](SRC-221-clicking-the-signed-in-person-in-the-header-opens.md)), holds the link to the person's GitHub account and the person's capacity and absences.

As received, in the design session of 2026-11-03, asked whether settings opens the GitHub account link and the capacity and absences screen: "yes yes those."

Split by Claude at the owner's request in the same session ("2 yes"), after the quality review found the earlier item bundled.
