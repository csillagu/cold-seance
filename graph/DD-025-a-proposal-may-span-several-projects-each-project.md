# DD-025: A proposal may span several projects; each project approves its own part

## Decision

A proposal may span several projects. Each project's part is approved by someone with read-write access in that project.

## Alternatives considered

One proposal spanning several projects, versus splitting it so each project approves its own part.

## Trade-offs

Gives up splitting proposals per project.
