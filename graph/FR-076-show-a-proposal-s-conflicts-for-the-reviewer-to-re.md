# FR-076: Show a proposal's conflicts for the reviewer to resolve or drop

The system must show as a conflict, for the reviewer to resolve or drop, each change in a proposal whose input on the same task was edited by someone else after the proposal was created, or whose task was deleted ([DD-022](DD-022-proposal-conflicts-are-real-conflicts-only.md)).

It serves [UC-012](UC-012-review-and-approve-an-ai-proposal.md).
