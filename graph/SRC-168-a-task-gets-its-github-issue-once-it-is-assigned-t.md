# SRC-168: A task gets its GitHub issue once it is assigned to a repository

A task has no GitHub issue until it is assigned to a repository; then its issue is created ([SRC-066](SRC-066-tasks-planned-in-the-tool-create-their-github-issu.md)). Some tasks have no GitHub issue counterpart.

As received, asked in which repository a task's issue is created when the project has several, and when it is created: "none, until assigned" and "There are tasks without github issue counterpart". Asked what "assigned" meant: "until it is assigned to a repo."
