# DD-015: Start and hold come from the GitHub Projects status field; finish is closing the issue

## Decision

Start and hold are set through the GitHub Projects status field; finish is closing the issue.

## Alternatives considered

Labels, a Projects status field, or assignment.

## Trade-offs

Gives up labels and assignment.

## Serves

This decision serves [SRC-058](SRC-058-start-from-github.md), [SRC-059](SRC-059-hold-from-github.md).
