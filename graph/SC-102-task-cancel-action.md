# SC-102: Task cancel action

The action that cancels a task in the tool. It is part of the React frontend ([DD-045](DD-045-the-frontend-uses-react-built-with-vite.md)).

It is done when someone whose role allows it can cancel a task from where the task is shown, and the task then shows as cancelled.

It delivers:

- [FR-027](FR-027-let-a-task-be-cancelled-in-the-tool.md): Let a task be cancelled in the tool
