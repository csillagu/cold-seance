# SRC-286: A project admin adding a member is suggested every account's username

When a project admin adds a member to a project, the tool suggests usernames as they type, from every account in the tool. Every project admin can therefore see every account's username.

As received, in the design session of 2026-11-23, recorded in issue #256 (the UI/UX review of the demo deployment). Asked, about item 22 ("A member is added by typing the exact username. There are no suggestions"), "Listing accounts is system-admin only today. What may a project admin's username suggestions show?", with the options "Every account" ("Suggest any account's username as the admin types, so every project admin can see all usernames."), "Shared accounts only" and "Keep exact username", the owner chose "Every account".

Not stated: whether the same suggestions are given when a group admin adds a group member, and whether anything besides the username is shown.
