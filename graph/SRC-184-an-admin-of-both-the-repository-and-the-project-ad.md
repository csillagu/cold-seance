# SRC-184: An admin of both the repository and the project adds it without a separate approval

A person who is admin of both a repository ([SRC-180](SRC-180-repositories-are-their-own-item-in-the-tool-with-a.md)) and a project can add the repository to that project without a separate approval ([SRC-181](SRC-181-a-repository-s-admins-approve-adding-it-to-a-proje.md)).

As received, asked whether someone who is admin of both the repository and the project can add it without a separate approval: "yes".
