# SRC-235: The project list shows projects reached through groups

The plain list of a person's projects also shows the projects they hold a role in through a group ([SRC-139](SRC-139-project-access-also-comes-through-groups.md)), not only those they hold a role in directly.

As received, in the design session of 2026-11-04, told that the project search included projects reached through groups but the plain project list showed only projects held directly: "Plain project list should show roles through groups." Claude reads "show roles through groups" as listing the projects in which the person holds a role through a group.
