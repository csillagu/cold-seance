# FR-178: Keep a project's tasks from a repository after its approval is withdrawn

When a repository admin withdraws a project's approval for the repository ([FR-172](FR-172-let-a-repository-admin-withdraw-an-approval-given-.md)), the system must keep the tasks the project already has from that repository ([SRC-190](SRC-190-a-withdrawn-approval-stops-the-project-pulling-its.md)).

It serves [UC-037](UC-037-withdraw-a-project-s-approval-for-a-repository.md).
