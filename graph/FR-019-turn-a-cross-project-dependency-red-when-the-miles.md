# FR-019: Turn a cross-project dependency red when the milestone lies after the task's start

When a milestone another project owns lies after the start of a task that depends on it, the system must show the dependency in red in the dependent project and leave the dependent task's dates as they are ([SRC-048](SRC-048-shared-milestones-one-owning-project-others-can-de.md)).

It serves [UC-002](UC-002-reschedule-work-in-a-project.md), [UC-005](UC-005-depend-on-another-project-s-milestone.md) and [UC-006](UC-006-resolve-a-cross-project-red-flag.md).
