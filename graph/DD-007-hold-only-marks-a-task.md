# DD-007: Hold only marks a task

## Decision

Hold only marks a task. It doesn't move the task's planned finish or remove its load.

## Alternatives considered

Extending the task's planned finish while it is on hold, versus only marking it.

## Trade-offs

Gives up extending the finish.

## Serves

This decision serves [SRC-059](SRC-059-hold-from-github.md).

Origin: the stakeholder answered "11 yes"; the drafting agent read that as agreeing with "only mark" and said so, and the stakeholder did not confirm or correct it.
