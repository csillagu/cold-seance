# FR-061: Ask for the project when a task is created in a cross-project view

When a task is created in a view that covers several projects, the system must ask which project it goes in, offering only the projects the viewer can write to; if the view's filter allows only one project, it must use that one ([SRC-117](SRC-117-creating-a-task-in-a-cross-project-view-asks-for-i.md)).

It serves [UC-024](UC-024-work-in-a-cross-project-view.md).
