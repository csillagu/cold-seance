The screen that shows every group to everyone, lets anyone logged in create one, and lets a system admin delete one. It is part of the React frontend ([DD-045](DD-045-the-frontend-uses-react-built-with-vite.md)).

- [FR-121](FR-121-let-anyone-logged-in-create-a-group.md): Let anyone logged in create a group

- [FR-126](FR-126-let-only-system-admins-delete-a-group.md): Let only system admins delete a group
