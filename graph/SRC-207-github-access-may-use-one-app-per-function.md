# SRC-207: GitHub access may use one App per function

The tool may use a separate GitHub App for each of its functions on GitHub: reading issues, writing to issues, and the Projects status field. It may also use one App for all of them, by giving the same App for every function.

As received, in the design session of 2026-11-02, asked who may use the GitHub App setup page: "one app per function can be used (or the same if the same secret is entered into all fields)".

As received, in the design session of 2026-11-03, asked whether the functions are separate Apps for reading issues, writing to issues and the Projects status field: "Your take on functions is correct".

Using one App for all functions is kept here rather than split off: the owner gave it as the other side of the same choice, in the same sentence.
