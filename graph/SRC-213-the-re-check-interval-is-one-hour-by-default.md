# SRC-213: The re-check interval is one hour by default

The interval of the re-check of linked issues, set in configuration ([SRC-212](SRC-212-settings-such-as-the-re-check-interval-are-given.md)), is one hour unless the configuration sets another.

As received, in the design session of 2026-11-03, asked whether the default interval should be one hour: "default one hour".
