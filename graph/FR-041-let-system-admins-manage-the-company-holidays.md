# FR-041: Let system admins manage the company holidays

The system must let system admins, the people who create accounts, manage the company holidays in the global calendar ([SRC-128](SRC-128-company-holidays-are-managed-by-the-system-admins.md), [SRC-097](SRC-097-no-self-registration-a-system-admin-creates-accoun.md)), and reject changes to them from anyone else ([SRC-165](SRC-165-only-system-admins-can-change-the-company-holidays.md)).

It serves [UC-028](UC-028-maintain-the-company-holiday-calendar.md).
