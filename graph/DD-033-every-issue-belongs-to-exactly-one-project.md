# DD-033: Every issue belongs to exactly one project

## Decision

Every issue is assumed to belong to exactly one project, with no extra mapping rules.

## Alternatives considered

A per-project repo mapping set by the project admin (the drafting agent's suggestion), versus assuming it.

## Rationale

As received: "this is irrelevant"; "tool can just assume that every issue is in a project".

## Trade-offs

Gives up mapping rules.

Open question: whether "project" here meant the GitHub Project is still unanswered.
