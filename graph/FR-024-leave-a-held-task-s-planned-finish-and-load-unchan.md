# FR-024: Leave a held task's planned finish and load unchanged

When a task is put on hold, the system must only mark it as on hold, leaving its planned finish and its load as they were ([DD-007](DD-007-hold-only-marks-a-task.md)).

It serves [UC-007](UC-007-track-task-status-in-the-tool.md), [UC-008](UC-008-work-on-an-issue-from-github.md) and [UC-029](UC-029-set-the-status-of-a-task-i-am-assigned-to.md).
