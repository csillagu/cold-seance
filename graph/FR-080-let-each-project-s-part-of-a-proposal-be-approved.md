# FR-080: Let each project's part of a proposal be approved in that project

For a proposal that spans several projects, the system must let each project's part be approved only by someone with the read-write role in that project ([DD-025](DD-025-a-proposal-may-span-several-projects-each-project.md), [SRC-080](SRC-080-a-person-with-write-access-edits-approves-or-rejec.md)).

Not stated: what happens to the other parts when one project's part is approved and another's is rejected or expires.

It serves [UC-012](UC-012-review-and-approve-an-ai-proposal.md).
