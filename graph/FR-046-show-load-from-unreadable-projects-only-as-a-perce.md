# FR-046: Show load from unreadable projects only as a percentage

The system must show a person's total load across all projects to every viewer, with the exact tasks behind it for projects the viewer can read, and the load from other projects only as a percentage, such as "other projects: 60%" ([DD-014](DD-014-load-visibility-across-projects.md)).
