# FR-099: Accept status changes from GitHub whatever the person's role in the tool

The system must accept a start, hold, finish or cancel made on GitHub whoever made it, whatever their role in the tool, or none ([SRC-193](SRC-193-a-status-change-on-github-counts-whoever-made-it.md), [SRC-134](SRC-134-anyone-can-work-on-a-task-s-issue-through-github.md), [SRC-002](SRC-002-the-tool-is-the-single-source-of-truth-for-plannin.md), [SRC-171](SRC-171-cancelling-a-task-and-closing-its-issue-as-not-pla.md)).

It serves [UC-008](UC-008-work-on-an-issue-from-github.md).
