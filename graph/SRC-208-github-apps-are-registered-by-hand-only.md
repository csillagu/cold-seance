# SRC-208: GitHub Apps are registered by hand only

The GitHub Apps the tool uses are registered by hand on GitHub by whoever installs the tool. The tool does not create them; registering by hand is the only way.

As received, in the design session of 2026-11-03, asked whether entering the App by hand replaces creating it from the tool in one step: "typed by hand must be an option".

As received, later in the same session, told that the setup page offered both creating the App and entering it by hand: "What is both ways of creating an app? The only way should be user updating it manually."
