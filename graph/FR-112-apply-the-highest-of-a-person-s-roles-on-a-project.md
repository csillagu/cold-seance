# FR-112: Apply the highest of a person's roles on a project

Where a person holds more than one role on a project, directly or through groups, the system must apply the highest, so read plus write is write ([SRC-140](SRC-140-where-a-person-has-several-roles-on-a-project-the.md)).

It serves [UC-018](UC-018-create-a-group-and-give-it-access-to-projects.md), [UC-025](UC-025-manage-a-project-s-members.md), [UC-030](UC-030-manage-a-group-s-members.md), [UC-031](UC-031-leave-a-group.md) and [UC-032](UC-032-delete-a-group.md).
