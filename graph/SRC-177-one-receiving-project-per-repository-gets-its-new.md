# SRC-177: One receiving project per repository gets its new issues

Of the projects that pull issues from a repository ([SRC-174](SRC-174-several-projects-can-pull-issues-from-the-same-rep.md)), one is marked as the one that receives the repository's new issues. Every new issue from that repository goes there, as an unscheduled task ([SRC-169](SRC-169-a-project-sets-which-repositories-it-pulls-issues.md)).

As received: the drafting agent proposed three options for which project gets a new issue from a repository several projects pull from. Option A read: "Of the projects that pull from a repository, one is marked as the one that receives its new issues. Every new issue goes there as an unscheduled task." The stakeholder chose it: "1A". The wording is the drafting agent's.

Not stated here: who marks the receiving project, and what happens when it stops pulling issues from the repository. Both were answered later; see SRC-178, SRC-190 and SRC-215.
