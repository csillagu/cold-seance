# SC-089: Personal working calendar screen

The screen on which a person enters their own holidays, and a system admin changes anyone's. It is part of the React frontend ([DD-045](DD-045-the-frontend-uses-react-built-with-vite.md)).

It is done when a person can enter holidays in their own calendar, with no setting for a weekend of their own, and a system admin can do the same for anyone.

It delivers:

- [FR-039](FR-039-let-each-person-maintain-their-own-working-calenda.md): Let each person maintain their own working calendar
- [FR-150](FR-150-let-a-system-admin-change-anyone-s-capacity-absenc.md): Let a system admin change anyone's capacity, absences and calendar
