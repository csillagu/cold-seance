# SRC-224: A project search finds only the projects the person has access to

A search in the header's project search bar ([SRC-220](SRC-220-the-header-holds-a-project-search-bar.md)) finds only the projects the person searching has access to.

As received, in the design session of 2026-11-03, asked what the header should hold: "1 search bar, where you can search for projects (only the ones you have access to) signed in person, when clicked settings, calendar, api tokens comes up, that can be accessed from there." Claude reads it as two things in the header, the search bar and the signed-in person. This item records "only the ones you have access to".

Split by Claude at the owner's request in the same session ("2 yes"), after the quality review found the earlier item bundled.
