# FR-143: Mark one receiving project for each repository

The system must let a project admin mark one of the projects that pull issues from a repository as the one that receives the repository's new issues ([SRC-177](SRC-177-one-receiving-project-per-repository-gets-its-new.md), [SRC-178](SRC-178-the-receiving-project-is-marked-by-a-project-admin.md)).

Not stated: whether that is the admin of the receiving project or of any project pulling from the repository, and what happens when the receiving project stops pulling issues from it.

It serves [UC-009](UC-009-triage-a-task-that-arrived-from-github.md) and [UC-025](UC-025-manage-a-project-s-members.md).
