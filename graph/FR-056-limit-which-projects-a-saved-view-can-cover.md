# FR-056: Limit which projects a saved view can cover

The system must limit a saved view kept in a project to that project, one kept in a group to the group's projects, and a personal one to what its owner can read; group and personal views can cover several projects ([SRC-111](SRC-111-views-are-kept-in-a-project-a-group-or-personally.md), [SRC-109](SRC-109-views-can-cover-several-projects.md)).

It serves [UC-014](UC-014-create-a-saved-view.md).
