# FR-011: Block moving a task to a forbidden date

The system must reject any change that moves a task onto one of its forbidden dates ([SRC-123](SRC-123-moving-a-task-to-a-forbidden-date-is-blocked.md), [SRC-124](SRC-124-forbidden-dates-come-from-the-assignees-calendars.md), [SRC-125](SRC-125-a-task-with-no-assignees-takes-its-forbidden-dates.md), [SRC-126](SRC-126-company-holidays-are-forbidden-for-every-task.md)), whether the change comes through the UI, the REST API or the MCP server ([SRC-123](SRC-123-moving-a-task-to-a-forbidden-date-is-blocked.md)).

It serves [UC-002](UC-002-reschedule-work-in-a-project.md), [UC-020](UC-020-maintain-my-own-working-calendar.md) and [UC-028](UC-028-maintain-the-company-holiday-calendar.md).
