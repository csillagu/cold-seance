# SRC-099: The GitHub App is installed per repo by the repo's admin

The GitHub App is installed on each repo by that repo's admin. It needs read and write access to issues, and to the GitHub Projects used for the status field.

As received: "is just installed to repos by the repo admin". This is also how GitHub Apps are installed.
