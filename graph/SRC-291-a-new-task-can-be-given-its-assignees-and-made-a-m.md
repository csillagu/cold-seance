# SRC-291: A new task can be given its assignees and made a milestone when it is created

The form that creates a task also takes the task's assigned people and whether it is a milestone. Eligibility is still set after the task is created.

As received, in the design session of 2026-11-23, recorded in issue #256 (the UI/UX review of the demo deployment). Asked, about item 34 ("The New task form has no assignees, eligibility or milestone fields"), "Which should it get?", with the options "Assignees", "Eligibility", "Milestone" and "None", the owner chose "Milestone" and "Assignees".
