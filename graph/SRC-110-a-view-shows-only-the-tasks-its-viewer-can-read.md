# SRC-110: A view shows only the tasks its viewer can read

A view never grants access. When someone opens a saved view ([SRC-108](SRC-108-kanban-and-gantt-support-saved-views.md)), it shows only the tasks that person can read, so two people opening the same view can see different tasks.

Proposed in the design session and accepted: "makes sense".
