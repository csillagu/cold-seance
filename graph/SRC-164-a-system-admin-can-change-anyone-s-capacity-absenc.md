# SRC-164: A system admin can change anyone's capacity, absences and calendar

Besides the person themselves ([SRC-130](SRC-130-each-person-records-their-own-capacity.md), [SRC-129](SRC-129-each-person-records-their-own-absences.md), [SRC-120](SRC-120-each-person-maintains-their-own-working-calendar.md)), a system admin ([SRC-097](SRC-097-no-self-registration-a-system-admin-creates-accoun.md)) can change a person's capacity, absences and calendar.

As received, asked whether anyone other than the person can change their capacity, absences or calendar: "sys admin".
