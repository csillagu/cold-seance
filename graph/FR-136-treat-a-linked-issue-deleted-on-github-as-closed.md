# FR-136: Treat a linked issue deleted on GitHub as closed

When a linked issue is deleted on GitHub, the system must handle it as if the issue had been closed ([SRC-151](SRC-151-a-linked-issue-deleted-on-github-counts-as-closed.md)), with the same results as in [FR-093](FR-093-finish-a-task-when-its-issue-is-closed-on-github.md) and [FR-095](FR-095-revert-github-status-changes-that-break-a-constrai.md).

It serves [UC-008](UC-008-work-on-an-issue-from-github.md).
