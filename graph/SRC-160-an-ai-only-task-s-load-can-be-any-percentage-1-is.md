# SRC-160: An AI-only task's load can be any percentage; 1% is recommended

The person load of an AI-only task can be any percentage; 1% is recommended, offered as the default value in the UI. This replaces the "about 0–1%" first recorded in SRC-038.

As received, asked whether an AI-only task's load is exactly 0% or 1%: "it can be anything, 1 percent is recommended".

Asked how the 1% recommendation is offered: "default value in ui".
