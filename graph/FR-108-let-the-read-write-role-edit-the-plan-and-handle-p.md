# FR-108: Let the read-write role edit the plan and handle proposals

The system must let a person with the read-write role in a project edit its tasks, plans and assignments, and review, edit and approve its AI proposals ([SRC-092](SRC-092-read-write-role.md)).

It serves [UC-001](UC-001-plan-a-task-in-a-project.md), [UC-002](UC-002-reschedule-work-in-a-project.md), [UC-003](UC-003-assign-people-to-a-task.md), [UC-007](UC-007-track-task-status-in-the-tool.md), [UC-012](UC-012-review-and-approve-an-ai-proposal.md) and [UC-021](UC-021-link-tasks-with-constraints.md).
