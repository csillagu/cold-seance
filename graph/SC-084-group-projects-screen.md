# SC-084: Group projects screen

The screen on which projects are added to a group. It is part of the React frontend ([DD-045](DD-045-the-frontend-uses-react-built-with-vite.md)).

It is done when anyone can add a new project to a group, a project's admin can add an existing project, and no one else can add an existing project.

It delivers:

- [FR-123](FR-123-let-anyone-add-a-new-project-to-a-group-and-only-i.md): Let anyone add a new project to a group, and only its admin an existing one
