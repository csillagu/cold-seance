# SRC-119: A project someone cannot see is reported as not visible

When a project is not visible to someone, the tool tells them explicitly that the project is not visible, rather than a vague message.

As received: "if a project is not visible by someone, tell explicitly, that the project isnt visible, dont say \"not found or deleted or no permission\"".
