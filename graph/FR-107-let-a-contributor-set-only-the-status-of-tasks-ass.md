# FR-107: Let a contributor set only the status of tasks assigned to them

The system must let a person with the contributor role mark a task they are assigned to as in progress, on hold or finished, and reject from them every other edit, including to tasks they are not assigned to, cancelling a task and reopening a finished one ([SRC-136](SRC-136-contributor-role.md)).

It serves [UC-029](UC-029-set-the-status-of-a-task-i-am-assigned-to.md).
