# SRC-194: An AI-only task's load can be 0, a fraction or above 100%

The person load of an AI-only task can be any percentage ([SRC-160](SRC-160-an-ai-only-task-s-load-can-be-any-percentage-1-is.md)), including 0%, fractions of a percent and values above 100%.

As received, asked whether "any percentage" includes 0, values above 100% and fractions: "yes yes yes fucking yes.  ANY PERCENT".
