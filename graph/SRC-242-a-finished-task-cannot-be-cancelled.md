# SRC-242: A finished task cannot be cancelled

A task that is done cannot be cancelled.

As received, in the design session of 2026-11-04, in the review of the task cancellation (SC-038, PR #86). The owner was asked whether cancelling a task that is already done should be allowed. If it were, its blockers would be passed on to tasks that may already have started, and its actual start and finish would be kept. The owner chose "Refuse for done tasks".
