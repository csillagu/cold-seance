# DD-036: A baseline is a named snapshot of planned dates; multiple per project

## Decision

A baseline is a named snapshot of every task's planned start and finish in a project (e.g. "v1 approved", "v2 after re-plan"). A project keeps multiple baselines.

## Alternatives considered

Baseline custom fields, versus "several baselines ... as snapshots".

## Trade-offs

Gives up baseline custom fields.

## Serves

This decision serves [SRC-053](SRC-053-planned-dates-are-compared-against-baselines-and-a.md).

Origin: the drafting agent named both options and chose multiple snapshots itself when writing the requirements document. The stakeholder never weighed in.
