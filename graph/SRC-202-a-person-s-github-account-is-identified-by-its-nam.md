# SRC-202: A person's GitHub account is identified by its name

When a person's account in the tool is linked to their GitHub account ([SRC-150](SRC-150-a-person-s-github-account-is-linked-by-the-person.md)), the GitHub account is given by its name.

As received, asked whether a GitHub account is identified by typing its name or by signing in to GitHub: "neme but already in the docs". Claude reads "neme" as "name". The stakeholder says this is already in the docs; Claude did not find it in docs/initial-requirements.md or docs/src-dd-classification.md, which mention only people without a GitHub account.
