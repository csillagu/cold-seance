# SRC-202: A person's GitHub account is identified by its name

When a person's account in the tool is linked to their GitHub account ([SRC-150](SRC-150-a-person-s-github-account-is-linked-by-the-person.md)), the GitHub account is given by its name, which the user types in.

As received, asked whether a GitHub account is identified by typing its name or by signing in to GitHub: "neme but already in the docs". Claude reads "neme" as "name".

As received, in the design session of 2026-11-03, asked where this is stated: "Github account identification: there is a dd or src about it. User types in the name." Claude found no other item that says so; DD-027 (local accounts only) rules out signing in with GitHub.
