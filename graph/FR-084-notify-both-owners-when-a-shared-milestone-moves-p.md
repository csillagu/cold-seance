# FR-084: Notify both owners when a shared milestone moves past a dependent task's start

When a shared milestone moves past the start of a task that depends on it in another project, the system must notify the admins of both projects ([SRC-050](SRC-050-both-owners-get-an-in-app-notification.md), [SRC-154](SRC-154-a-project-s-owners-are-its-admins.md)); it offers them no change-request flow ([DD-012](DD-012-no-cross-project-change-request-flow-in-v1.md)).

It serves [UC-002](UC-002-reschedule-work-in-a-project.md) and [UC-006](UC-006-resolve-a-cross-project-red-flag.md).
