# SRC-287: A project's members screen lists the groups with access to the project

A project's members screen lists the groups that hold a role on the project, each with its role and a link to the group. It does not list the groups' members one by one.

As received, in the design session of 2026-11-23, recorded in issue #256 (the UI/UX review of the demo deployment). Asked, about item 23 ("Roles held through groups are not shown"), "Should it show them?", with the options "List them read-only", "List the groups" ("List only the groups with access and their role, linking to each group.") and "Leave as is", the owner chose "List the groups".
