# SRC-140: Where a person has several roles on a project, the highest wins

Where a person holds more than one role on a project, directly ([DD-034](DD-034-roles-are-assigned-per-project.md)) or through groups ([SRC-139](SRC-139-project-access-also-comes-through-groups.md)), the highest wins, so read plus write is write.
