# SRC-191: An hour is an acceptable delay for GitHub sync and notifications

An hour, the interval of the re-check of linked issues ([SRC-073](SRC-073-hourly-reconciliation-of-all-linked-issues.md)), is an acceptable worst-case delay for keeping GitHub in step with the tool, for reverting changes made on GitHub, and for notifications ([SRC-015](SRC-015-notifications-for-new-red-flags-proposals-waiting.md)).

As received, asked whether the hourly re-check is an acceptable worst case for notifications and for sync with GitHub, including reverts, or whether a tighter limit is wanted: "hourly is ok."
