# FR-001: Store each task with its minimum fields

The system must store each task with at least: title, description, project, status, planned start and finish (or a duration), effort, AI share, eligibility expression, assigned people, and an optional linked GitHub issue ([SRC-023](SRC-023-minimum-task-fields.md)).

It serves [UC-001](UC-001-plan-a-task-in-a-project.md).
