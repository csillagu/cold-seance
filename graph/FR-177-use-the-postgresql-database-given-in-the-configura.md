# FR-177: Use the PostgreSQL database given in the configuration

The system must use the PostgreSQL database whose address is given in its configuration, including an external hosted PostgreSQL service such as Neon, instead of the one it is installed with ([SRC-200](SRC-200-the-tool-can-use-an-external-hosted-postgresql-suc.md), [SRC-196](SRC-196-the-tool-s-data-is-stored-in-postgresql.md)).

No use case covers installing the tool; this obligation rests on the linked items directly.
