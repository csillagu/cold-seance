# DD-023: Proposal changes are grouped

## Decision

The AI groups changes that only make sense together. A group is approved, edited or dropped as one.

## Alternatives considered

Approving changes individually, versus in groups.

## Rationale

Proposed changes often only make sense together.

## Trade-offs

Gives up per-change approval.
