# SRC-217: Tasks kept after a withdrawal stay linked but are not synced

The tasks a project keeps from a repository after its approval is withdrawn ([SRC-190](SRC-190-a-withdrawn-approval-stops-the-project-pulling-its.md)) stay linked to their GitHub issues, but the tool stops syncing them with those issues.

As received, in the design session of 2026-11-03, asked whether those tasks stay linked to their GitHub issues, with the options "Linked, still mirrored", "Linked, not mirrored" ("Tasks remember their issue, but the tool stops syncing with it.") and "Unlinked": "Linked, not mirrored".
