# FR-196: Mark a floating milestone done when what it is blocked by is done

The system must mark a floating milestone done once every task it is blocked by is done ([SRC-236](SRC-236-a-milestone-is-a-kind-of-task-fixed-date-or-floati.md)).

It serves [UC-021](UC-021-link-tasks-with-constraints.md).

Origin: composed by Claude from the items linked above, for issue #65. The wording is Claude's, not the stakeholder's; every obligation rests on a linked item. What happens to a floating milestone that is blocked by nothing, or to one whose blocker is reopened after it is done, is not stated.
