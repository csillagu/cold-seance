# FR-196: Mark a floating milestone done when what it is blocked by is done

The system must mark a floating milestone done once every task it is blocked by is done, and keep it done if one of those tasks is later reopened ([SRC-236](SRC-236-a-milestone-is-a-kind-of-task-fixed-date-or-floati.md)).

It serves [UC-021](UC-021-link-tasks-with-constraints.md).

Origin: composed by Claude from the items linked above, for issue #65. The wording is Claude's, not the stakeholder's; every obligation rests on a linked item. That it stays done when a blocker is reopened was added from the owner's answer in the design session of 2026-11-04. What happens to a floating milestone that is blocked by nothing is not stated.
