# FR-093: Finish a task when its issue is closed on GitHub

When a task's issue is closed on GitHub, directly or by a merged pull request that closes it, the system must set the task to done and record its actual finish ([SRC-060](SRC-060-finish-from-github-close-issue.md), [SRC-069](SRC-069-a-merged-pr-that-closes-an-issue-counts-as-finish.md)).

It serves [UC-008](UC-008-work-on-an-issue-from-github.md).
