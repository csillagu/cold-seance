# FR-023: Record a task's actual finish when it is finished

The system must record a task's actual finish when it is finished, in the tool or from GitHub ([SRC-056](SRC-056-actual-finish-is-recorded-when-a-task-is-finished.md)).

It serves [UC-007](UC-007-track-task-status-in-the-tool.md), [UC-008](UC-008-work-on-an-issue-from-github.md) and [UC-029](UC-029-set-the-status-of-a-task-i-am-assigned-to.md).
