# FR-035: Count only assigned people toward person load

The system must count only a task's assigned people toward person load; eligible people who are not assigned carry none of it ([SRC-034](SRC-034-only-assigned-people-count-toward-person-load.md)).

It serves [UC-003](UC-003-assign-people-to-a-task.md) and [UC-004](UC-004-check-people-s-load-across-projects.md).
