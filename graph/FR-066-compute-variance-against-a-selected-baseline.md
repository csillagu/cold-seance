# FR-066: Compute variance against a selected baseline

The system must compute variance per task and per milestone as the actual dates, or the current plan where there are none yet, minus the selected baseline's dates ([DD-037](DD-037-variance-is-computed-not-stored.md), [SRC-053](SRC-053-planned-dates-are-compared-against-baselines-and-a.md)). It must count variance in working days of the global calendar, leaving out its weekend days and company holidays ([SRC-244](SRC-244-variance-is-counted-in-working-days-of-the-global.md)).

It serves [UC-023](UC-023-review-variance-against-a-baseline.md).
