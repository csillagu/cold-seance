# FR-092: Put a task on hold when it is put on hold on GitHub

When a task's issue is put on hold on GitHub, through the Projects status field ([DD-015](DD-015-start-and-hold-come-from-the-github-projects-statu.md)), the system must set the task to on hold ([SRC-059](SRC-059-hold-from-github.md)).

It serves [UC-008](UC-008-work-on-an-issue-from-github.md).
