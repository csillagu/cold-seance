# SRC-220: The header holds a project search bar and the signed-in person, who opens settings, calendar and API tokens

The header of the frontend's layout ([SRC-219](SRC-219-the-frontend-layout-has-a-header-and-navigation-an.md)) holds a search bar in which a person searches for projects, finding only the projects they have access to. It also shows the signed-in person. Clicking the signed-in person brings up settings, calendar and API tokens, which can be reached from there.

As received, in the design session of 2026-11-03, asked what the header should hold: "1 search bar, where you can search for projects (only the ones you have access to) signed in person, when clicked settings, calendar, api tokens comes up, that can be accessed from there." Claude reads it as two things in the header, the search bar and the signed-in person, with the click on the signed-in person bringing up the three.
