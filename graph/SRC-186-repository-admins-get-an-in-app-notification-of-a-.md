# SRC-186: Repository admins get an in-app notification of a project's request

A repository's admins learn of a project's request to add the repository ([SRC-181](SRC-181-a-repository-s-admins-approve-adding-it-to-a-proje.md)) through an in-app notification, as with the tool's other notifications ([DD-003](DD-003-notifications-are-in-app-only.md)).

As received, asked how a repository admin learns that a project wants their repository: "in app notifications, like usually".
