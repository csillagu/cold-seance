# SRC-243: A project's admin removes a repository from the project

A project's admin can remove a repository from the repositories the project pulls issues from.

As received, in the design session of 2026-11-05. Claude reported that the first step of TC-212 has a project's admin remove a repository from the repositories the project pulls issues from, and that no SC offers it. The owner answered: "ok thats needs to be supported, maybe create a new sc?"

Not stated: what becomes of the tasks the project already has from the repository, and whether the project's repository settings screen offers the removal.
