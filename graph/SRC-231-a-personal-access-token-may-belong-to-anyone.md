# SRC-231: A personal access token may belong to anyone

A personal access token the tool uses ([SRC-229](SRC-229-github-access-may-use-personal-access-tokens-beside.md)) may belong to any GitHub account; it need not be an account used by the tool alone.

As received, in the design session of 2026-11-03, asked "Token owner: must the token belong to an account used only by the tool? If a person's own account is used, their manual changes on GitHub look the same as the tool's.": "no, it can belong to anyone."
