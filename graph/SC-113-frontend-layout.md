# SC-113: Frontend layout

The layout of the React frontend ([DD-045](DD-045-the-frontend-uses-react-built-with-vite.md)): the frame in which the frontend's pages, screens and views are shown. The pages, screens and views are components of their own; this deliverable is the frame around them. It is done when every page, screen and view of the frontend is shown inside the layout.

What the layout holds besides the frame, such as navigation between the screens, is not stated. Whether the sign-in page is shown inside it is not stated either.

No FR states the layout, so this component delivers none.
