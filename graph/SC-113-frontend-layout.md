# SC-113: Frontend layout

The layout of the React frontend ([DD-045](DD-045-the-frontend-uses-react-built-with-vite.md)): a header and navigation around the area in which the frontend's screens and views are shown ([SRC-219](SRC-219-the-frontend-layout-has-a-header-and-navigation-an.md)). The sign-in page is shown outside it. The screens and views are components of their own; this deliverable is the layout around them. It is done when every screen and view of the frontend, apart from the sign-in page, is shown inside the layout with its header and navigation, and the sign-in page is shown without them.

What the header holds, and what the navigation leads to, are not stated.

No FR states the layout, so this component delivers none.
