# SRC-185: A repository admin can reject a project's request or withdraw an approval

A repository's admin can reject a project's request to add the repository ([SRC-181](SRC-181-a-repository-s-admins-approve-adding-it-to-a-proje.md)), and can withdraw an approval given earlier.

As received, asked whether a repository admin can reject a request or withdraw an approval later, and if so what then happens to that project's tasks from the repository: "yes".

Not stated: what happens to the project's tasks from the repository, and to the repository's link to the project, when an approval is withdrawn.
