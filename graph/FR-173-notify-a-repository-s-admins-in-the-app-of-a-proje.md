# FR-173: Notify a repository's admins in the app of a project's request

When a project's admin asks to add a repository to the project, the system must notify the repository's admins in the app ([SRC-186](SRC-186-repository-admins-get-an-in-app-notification-of-a-.md), [DD-003](DD-003-notifications-are-in-app-only.md)).

It serves [UC-034](UC-034-approve-adding-a-repository-to-a-project.md) and [UC-036](UC-036-reject-a-project-s-request-for-a-repository.md).
