# SRC-214: A GitHub App is given by its id and private key

Each GitHub App the tool uses is given to it by the App's id and its private key.

As received, in the design session of 2026-11-03, asked whether the fields are the App id, private key and webhook secret: "fields are app id, private key, why would webhook be relevant?". The webhook secret is taken up in SRC-209.
