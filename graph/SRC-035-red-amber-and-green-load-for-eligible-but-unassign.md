# SRC-035: Red, amber and green load for eligible but unassigned tasks

While a task has an eligibility expression but no assignment yet, the load view shows:

- **Red** when every valid combination overloads someone.
- **Amber** when some valid combinations overload someone and others don't.
- **Green** when at least one valid combination fits.

Origin: the drafting agent's proposal; never discussed.
