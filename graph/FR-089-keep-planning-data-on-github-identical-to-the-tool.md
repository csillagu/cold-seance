# FR-089: Keep planning data on GitHub identical to the tool

The system must mirror to GitHub, and keep identical there, the sub-issue relations of subtasks, the blocked-by relations of dependencies, the assignees of assigned people, and the fixed dates of milestones, putting any difference right within an hour at the latest ([SRC-191](SRC-191-an-hour-is-an-acceptable-delay-for-github-sync-and.md), [SRC-063](SRC-063-planning-data-is-mirrored-from-the-tool-to-github.md), [SRC-019](SRC-019-all-three-constraint-types-are-enforced-in-the-too.md)).
