# FR-034: Apply a task's load to each assigned person over its whole duration

The system must apply a task's person-load percentage, or the assignment's override, to each assigned person on every day of the task's duration ([DD-009](DD-009-person-load-is-a-percentage-applied-over-the-task.md), [DD-010](DD-010-the-person-load-percentage-can-be-overridden-per-a.md)).

It serves [UC-003](UC-003-assign-people-to-a-task.md) and [UC-004](UC-004-check-people-s-load-across-projects.md).
