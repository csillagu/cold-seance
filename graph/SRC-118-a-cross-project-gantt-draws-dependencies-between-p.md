# SRC-118: A cross-project Gantt draws dependencies between projects

A Gantt view that covers several projects ([SRC-109](SRC-109-views-can-cover-several-projects.md)) draws the dependencies between them: tasks that depend on another project's shared milestone ([SRC-048](SRC-048-shared-milestones-one-owning-project-others-can-de.md), [SRC-049](SRC-049-depending-on-another-project-s-milestone-requires.md)). Nothing done in one project changes another ([SRC-004](SRC-004-cross-project-effects-never-change-another-project.md)).

Proposed in the design session and accepted: "perfect".
