# FR-033: Let a single assignment override the task's person-load percentage

The system must let the person-load percentage be overridden for one assignment, replacing the task's default for that person, for example 30% on a long task ([DD-010](DD-010-the-person-load-percentage-can-be-overridden-per-a.md)).
