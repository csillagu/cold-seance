# SRC-144: The group admin manages the group's members

A group admin ([SRC-132](SRC-132-a-group-s-creator-becomes-its-admin.md)), that is, any member holding the admin role in the group, manages the group's members ([SRC-139](SRC-139-project-access-also-comes-through-groups.md)).

Origin: split out of [SRC-139](SRC-139-project-access-also-comes-through-groups.md), first recorded as DD-028. Asked whether "the group admin" is the same as a member with the admin role in the group, the stakeholder said: "same thing".
