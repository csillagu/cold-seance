# SRC-221: Clicking the signed-in person in the header opens settings, calendar and API tokens

The header of the frontend's layout ([SRC-219](SRC-219-the-frontend-layout-has-a-header-and-navigation-an.md)) shows the signed-in person. Clicking the signed-in person brings up settings, calendar and API tokens, each of which can be reached from there. Settings holds the link to the person's GitHub account and the person's capacity and absences.

As received, in the design session of 2026-11-03, asked what the header should hold: "1 search bar, where you can search for projects (only the ones you have access to) signed in person, when clicked settings, calendar, api tokens comes up, that can be accessed from there." Claude reads it as two things in the header, the search bar and the signed-in person; the search bar is SRC-220.

As received, in the same session, asked whether settings opens the GitHub account link and the capacity and absences screen: "yes yes those."
