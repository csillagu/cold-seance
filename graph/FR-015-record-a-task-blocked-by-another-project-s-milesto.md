# FR-015: Record a task blocked by another project's milestone

The system must let a task be blocked by a milestone that another project owns ([SRC-048](SRC-048-shared-milestones-one-owning-project-others-can-de.md)), whether fixed-date or floating ([SRC-236](SRC-236-a-milestone-is-a-kind-of-task-fixed-date-or-floati.md)), and record that dependency in the task's project.

It serves [UC-005](UC-005-depend-on-another-project-s-milestone.md).

Origin: composed by Claude from the items linked above, for issue #5. The wording is Claude's, not the stakeholder's; every obligation rests on a linked item. "Whether fixed-date or floating" was added for issue #65, from the owner's answer in the design session of 2026-11-04.
