# FR-176: Let a repository's admins remove other admins or step down

The system must let any admin of a repository remove another admin of it, or step down as its admin ([SRC-189](SRC-189-a-repository-s-admins-can-remove-other-admins-or-s.md)), unless that would leave the repository without an admin ([FR-175](FR-175-reject-leaving-a-repository-without-an-admin.md)).

It serves [UC-039](UC-039-remove-an-admin-from-a-repository.md).
