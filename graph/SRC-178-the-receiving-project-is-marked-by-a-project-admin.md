# SRC-178: The receiving project is marked by a project admin

The admin of the receiving project ([SRC-093](SRC-093-admin-role.md)) marks which project receives a shared repository's new issues ([SRC-177](SRC-177-one-receiving-project-per-repository-gets-its-new.md)).

As received, asked who marks the receiving project: "project admin". Asked whether this is the admin of the receiving project or of any project pulling from the repository: "receiving".
