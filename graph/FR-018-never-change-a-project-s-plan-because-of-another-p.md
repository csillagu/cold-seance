# FR-018: Never change a project's plan because of another project

The system must never change a project's plan because of a change in another project, through shared people or shared milestones ([SRC-004](SRC-004-cross-project-effects-never-change-another-project.md)).

It serves [UC-002](UC-002-reschedule-work-in-a-project.md), [UC-005](UC-005-depend-on-another-project-s-milestone.md), [UC-006](UC-006-resolve-a-cross-project-red-flag.md) and [UC-024](UC-024-work-in-a-cross-project-view.md).
