# FR-008: Treat each assigned person's days off as forbidden dates for the task

The system must treat a day off in the calendar of any one of a task's assigned people as a forbidden date for that task ([SRC-124](SRC-124-forbidden-dates-come-from-the-assignees-calendars.md), [SRC-120](SRC-120-each-person-maintains-their-own-working-calendar.md)).

It serves [UC-002](UC-002-reschedule-work-in-a-project.md) and [UC-020](UC-020-maintain-my-own-working-calendar.md).
