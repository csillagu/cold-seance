# FR-007: Skip a task's non-working days when scheduling it

When the system schedules a task, it must skip that task's forbidden dates ([SRC-121](SRC-121-scheduling-skips-non-working-days.md)), as determined by [FR-008](FR-008-treat-each-assigned-person-s-days-off-as-forbidden.md), [FR-009](FR-009-take-forbidden-dates-from-the-global-calendar-when.md) and [FR-010](FR-010-treat-company-holidays-and-weekends-as-forbidden-d.md).

It serves [UC-002](UC-002-reschedule-work-in-a-project.md), [UC-020](UC-020-maintain-my-own-working-calendar.md) and [UC-028](UC-028-maintain-the-company-holiday-calendar.md).
