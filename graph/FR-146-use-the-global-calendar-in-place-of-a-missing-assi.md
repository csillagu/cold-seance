# FR-146: Use the global calendar in place of a missing assignee calendar

When an assigned person has not filled in their own calendar, the system must use the global calendar in place of that person's calendar only, and still apply the other assigned people's own calendars ([SRC-163](SRC-163-for-an-assignee-without-a-calendar-the-global-cale.md), [SRC-125](SRC-125-a-task-with-no-assignees-takes-its-forbidden-dates.md), [SRC-124](SRC-124-forbidden-dates-come-from-the-assignees-calendars.md)).

It serves [UC-002](UC-002-reschedule-work-in-a-project.md).
