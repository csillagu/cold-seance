# SRC-234: A project search ignores spaces around the search text

A search in the header's project search bar ([SRC-220](SRC-220-the-header-holds-a-project-search-bar.md)) trims the search text: spaces before and after it do not count.

As received, in the design session of 2026-11-04, told that the project search did not trim its search text, so that a trailing space found nothing: "Trim it."
