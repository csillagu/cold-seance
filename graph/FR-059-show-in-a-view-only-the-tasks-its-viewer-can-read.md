# FR-059: Show in a view only the tasks its viewer can read

The system must show, in any view, only the tasks the person viewing it can read; a view never grants access ([SRC-110](SRC-110-a-view-shows-only-the-tasks-its-viewer-can-read.md)).

It serves [UC-014](UC-014-create-a-saved-view.md) and [UC-024](UC-024-work-in-a-cross-project-view.md).
