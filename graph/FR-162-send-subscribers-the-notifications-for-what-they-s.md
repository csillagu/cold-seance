# FR-162: Send subscribers the notifications for what they subscribed to

The system must send each subscriber the notifications about the issues and projects they subscribed to, within an hour at the latest ([SRC-191](SRC-191-an-hour-is-an-acceptable-delay-for-github-sync-and.md)): new red flags, proposals waiting for review, and changes the tool reverted on GitHub ([SRC-153](SRC-153-people-subscribe-to-issues-and-projects-write-and.md), [SRC-015](SRC-015-notifications-for-new-red-flags-proposals-waiting.md)).

It serves [UC-006](UC-006-resolve-a-cross-project-red-flag.md), [UC-008](UC-008-work-on-an-issue-from-github.md) and [UC-012](UC-012-review-and-approve-an-ai-proposal.md).
