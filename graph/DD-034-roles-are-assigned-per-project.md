# DD-034: Roles are assigned per project

## Decision

Roles are assigned per project, so a user can be read-write in one project and read-only in another.

## Alternatives considered

Global roles, versus per-project roles.

## Trade-offs

Gives up global roles.

## Serves

This decision serves [SRC-091](SRC-091-read-only-role.md), [SRC-092](SRC-092-read-write-role.md), [SRC-093](SRC-093-admin-role.md).

Origin: as received, "roles are per project." No reason was given.
