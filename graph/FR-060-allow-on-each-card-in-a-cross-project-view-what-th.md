# FR-060: Allow on each card in a cross-project view what the viewer's role there allows

In a view that covers several projects, the system must let the viewer do with each card whatever they could do with it from another view, where the view supports it, according to their role in the card's project, held directly or through a group ([SRC-138](SRC-138-a-cross-project-view-allows-whatever-the-viewer-ca.md), [DD-034](DD-034-roles-are-assigned-per-project.md), [SRC-139](SRC-139-project-access-also-comes-through-groups.md)).

It serves [UC-024](UC-024-work-in-a-cross-project-view.md) and [UC-029](UC-029-set-the-status-of-a-task-i-am-assigned-to.md).
