# SRC-187: A repository's admins can add other admins

A repository's admins ([SRC-180](SRC-180-repositories-are-their-own-item-in-the-tool-with-a.md)) can add other people as admins of the repository.

As received, asked whether a repository admin can add other admins: "yes".

Whether a repository's admins can remove other admins, or step down, was answered later; see SRC-189.
