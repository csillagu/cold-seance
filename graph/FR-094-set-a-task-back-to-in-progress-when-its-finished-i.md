# FR-094: Set a task back to in progress when its finished issue is reopened

When a finished task's issue is reopened on GitHub, the system must set the task back to in progress and clear its actual finish ([SRC-067](SRC-067-a-finished-issue-reopened-on-github-sets-the-task.md)).

It serves [UC-008](UC-008-work-on-an-issue-from-github.md).
