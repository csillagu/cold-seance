# FR-097: Undo planning edits made on GitHub

The system must not accept planning edits made on GitHub, to assignees, sub-issues or blocked-by relations, and must restore its own state there ([SRC-064](SRC-064-planning-edits-made-in-github-are-not-accepted.md), [SRC-002](SRC-002-the-tool-is-the-single-source-of-truth-for-plannin.md)).

Not stated: what the system does when a linked issue is deleted on GitHub, apart from a closed blocked issue (FR-095).

It serves [UC-008](UC-008-work-on-an-issue-from-github.md).
