# FR-097: Undo planning edits made on GitHub

The system must not accept planning edits made on GitHub, to assignees, sub-issues or blocked-by relations, and must restore its own state there within an hour at the latest ([SRC-191](SRC-191-an-hour-is-an-acceptable-delay-for-github-sync-and.md), [SRC-064](SRC-064-planning-edits-made-in-github-are-not-accepted.md), [SRC-002](SRC-002-the-tool-is-the-single-source-of-truth-for-plannin.md)).
