# DD-010: The person-load percentage can be overridden per assignment

## Decision

The person-load percentage can be overridden per assignment (e.g. 30% on a long task), replacing the default.

## Alternatives considered

Load always 100% or AI-adjusted, versus a custom percentage per assignment.

## Trade-offs

Gives up a fixed load.

## Serves

This decision serves [DD-009](DD-009-person-load-is-a-percentage-applied-over-the-task.md).
