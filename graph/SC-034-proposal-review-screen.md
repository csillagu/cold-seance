# SC-034: Proposal review screen

The React screen ([DD-045](DD-045-the-frontend-uses-react-built-with-vite.md)) where a reviewer opens a proposal, sees its live preview against the current plan ([DD-021](DD-021-proposal-live-preview-against-the-current-plan.md)) and its conflicts ([DD-022](DD-022-proposal-conflicts-are-real-conflicts-only.md)), edits, approves or rejects it group by group ([DD-023](DD-023-proposal-changes-are-grouped.md)), and confirms again if the plan changed since the preview.

It delivers:

- [FR-072](FR-072-preview-a-proposal-against-the-current-plan.md): Preview a proposal against the current plan
- [FR-074](FR-074-let-a-reviewer-edit-a-proposal-in-the-browser.md): Let a reviewer edit a proposal in the browser
- [FR-075](FR-075-let-a-reviewer-reject-a-proposal.md): Let a reviewer reject a proposal
- [FR-076](FR-076-show-a-proposal-s-conflicts-for-the-reviewer-to-re.md): Show a proposal's conflicts for the reviewer to resolve or drop
- [FR-078](FR-078-ask-the-reviewer-to-confirm-again-if-the-plan-chan.md): Ask the reviewer to confirm again if the plan changed since the preview
