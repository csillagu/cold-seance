# SRC-155: Who can read the audit log

System admins can read the whole audit log ([SRC-095](SRC-095-every-change-is-recorded-in-an-audit-log.md)). A project's admins and its members with the read-write role can read the audit log of their own projects only ([SRC-093](SRC-093-admin-role.md), [SRC-092](SRC-092-read-write-role.md)).

As received, asked who can read the audit log: "sys admin everything and project admin+writer  only their projects."
