# FR-183: Let a person search by name only the projects they can read

The system must let a person search for projects, and must return only the projects that person has access to ([SRC-220](SRC-220-the-header-holds-a-project-search-bar-that-finds-on.md)). A search matches on the project's name.

Origin: composed by Claude from the item linked above, for issue #15, from SRC-220. The wording is Claude's, not the stakeholder's; every obligation rests on a linked item. No UC covers searching for a project.
