# FR-187: Refuse to start when a GitHub function is given neither an App nor a token, or both

The system must refuse to start, naming the function, when its configuration gives one of its GitHub functions neither a GitHub App nor a personal access token ([SRC-233](SRC-233-the-tool-is-not-deployed-without-an-app-or-a-token.md)), or both ([DD-060](DD-060-a-github-function-is-given-an-app-or-a-personal-ac.md)).

No use case covers installing the tool; this obligation rests on the linked items directly.
