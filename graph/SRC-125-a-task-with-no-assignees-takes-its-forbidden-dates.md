# SRC-125: A task with no assignees takes its forbidden dates from a global company-holiday calendar

When a task has no assigned people, its forbidden dates come from a global calendar that holds company holidays.

As received, following "Forbidden dates should come from assignee calendars.": "If none, lets have a global one that has like company holidays". "If none" is read here as "if the task has no assigned people".
