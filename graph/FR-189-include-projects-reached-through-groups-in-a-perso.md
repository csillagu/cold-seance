# FR-189: Include projects reached through groups in a person's project list

The system must include, in the list of a person's projects, every project in which they hold a role through a group ([SRC-235](SRC-235-the-project-list-shows-projects-reached-through-gr.md), [FR-111](FR-111-give-group-members-their-group-role-on-every-proje.md)), as well as those in which they hold a role directly.

Origin: composed by Claude from the items linked above, for issue #61. The wording is Claude's, not the stakeholder's; every obligation rests on a linked item. No UC covers listing one's projects, and no other item states the project list itself.
