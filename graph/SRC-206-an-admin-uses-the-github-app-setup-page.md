# SRC-206: An admin uses the GitHub App setup page

The GitHub App setup page is used by an admin. Claude reads this as a system admin ([SRC-097](SRC-097-no-self-registration-a-system-admin-creates-accoun.md)), because the GitHub Apps belong to the whole installation rather than to one project; which admin is meant is not stated.

As received, in the design session of 2026-11-03, asked who may use the setup page: "Admin can use it".
