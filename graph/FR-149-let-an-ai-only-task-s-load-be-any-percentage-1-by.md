# FR-149: Let an AI-only task's load be any percentage, 1% by default

The system must accept any person-load percentage for an AI-only task, including 0%, fractions of a percent and values above 100%, and offer 1% as the default value in the UI ([SRC-194](SRC-194-an-ai-only-task-s-load-can-be-0-a-fraction-or-abov.md), [SRC-160](SRC-160-an-ai-only-task-s-load-can-be-any-percentage-1-is.md)).

It serves [UC-003](UC-003-assign-people-to-a-task.md).
