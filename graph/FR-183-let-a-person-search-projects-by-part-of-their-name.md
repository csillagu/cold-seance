# FR-183: Let a person search projects by part of their name, ignoring case

The system must let a person search for projects by name ([SRC-220](SRC-220-the-header-holds-a-project-search-bar.md)): a project matches when the search text is part of its name, whatever the case of either ([SRC-225](SRC-225-a-project-search-matches-part-of-the-name-ignoring.md)).

Origin: composed by Claude from the items linked above, for issue #15. The wording is Claude's, not the stakeholder's; every obligation rests on a linked item. The quality review found it bundled, and the owner asked for it to be split in the design session of 2026-11-03 ("2 yes"); limiting the results is FR-184. No UC covers searching for a project.
