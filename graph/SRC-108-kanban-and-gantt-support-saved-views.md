# SRC-108: Kanban and Gantt support saved views

People can create further named views of the Kanban and Gantt kinds, similar to views in GitHub Projects. Saved views are needed for the Kanban and Gantt only.

As received: "we need the ability to create further views. Lik MY kanban (in one project), kanban with just whatever, kanban of this part of the project. Same for gant too." On view kinds: "kanban and gant should be enough".
