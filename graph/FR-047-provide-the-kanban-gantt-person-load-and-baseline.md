# FR-047: Provide the Kanban, Gantt, person load and baseline variance views

The system must provide four view kinds: Kanban, Gantt, person load and baseline variance ([SRC-008](SRC-008-four-view-kinds-cover-manual-use.md)). What each view shows is set in [FR-048](FR-048-lay-out-the-kanban-in-columns-by-task-status.md) (Kanban), [FR-049](FR-049-show-the-schedule-dependencies-milestones-and-viol.md) and [FR-050](FR-050-show-a-baseline-as-bars-on-the-gantt.md) (Gantt), [FR-051](FR-051-show-each-person-s-load-per-day-across-all-project.md) (person load), and [FR-052](FR-052-keep-the-baseline-variance-view-read-only.md) and [FR-152](FR-152-compare-planned-baseline-and-actual-dates-in-the-b.md) (baseline variance).

It serves [UC-004](UC-004-check-people-s-load-across-projects.md), [UC-007](UC-007-track-task-status-in-the-tool.md), [UC-021](UC-021-link-tasks-with-constraints.md) and [UC-023](UC-023-review-variance-against-a-baseline.md).
