# SRC-193: A status change on GitHub counts whoever made it

A change to an issue on GitHub, such as a start, hold, finish or cancel, counts whoever made it ([SRC-134](SRC-134-anyone-can-work-on-a-task-s-issue-through-github.md)).

As received, asked whose status changes on GitHub count (anyone with write access to the repository, assignees only, or something else): "does not matter WHO changed the issue (or creates one) the point it that it changes."
