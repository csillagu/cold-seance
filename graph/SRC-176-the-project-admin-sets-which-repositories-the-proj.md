# SRC-176: The project admin sets which repositories the project pulls issues from

A project's admin sets which repositories the project pulls issues from ([SRC-169](SRC-169-a-project-sets-which-repositories-it-pulls-issues.md)). This setting is the "repo mapping" the admin role manages ([SRC-093](SRC-093-admin-role.md)).

As received, asked whether the "repo mapping" the admin role manages is this setting, so that the project admin sets it: "Yes".
