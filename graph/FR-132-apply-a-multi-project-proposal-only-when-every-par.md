# FR-132: Apply a multi-project proposal only when every part is approved

For a proposal that spans several projects, the system must apply none of its changes until every project's part has been approved ([SRC-157](SRC-157-a-proposal-spanning-several-projects-is-applied-on.md), [DD-025](DD-025-a-proposal-may-span-several-projects-each-project.md)).

It serves [UC-012](UC-012-review-and-approve-an-ai-proposal.md).
