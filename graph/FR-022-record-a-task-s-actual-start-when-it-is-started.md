# FR-022: Record a task's actual start when it is started

The system must record a task's actual start when it is started, in the tool or from GitHub ([SRC-055](SRC-055-actual-start-is-recorded-when-a-task-is-started.md)).

It serves [UC-007](UC-007-track-task-status-in-the-tool.md), [UC-008](UC-008-work-on-an-issue-from-github.md) and [UC-029](UC-029-set-the-status-of-a-task-i-am-assigned-to.md).
