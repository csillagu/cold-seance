# FR-044: Never move tasks to fix an overload

The system must accept a plan change that overloads someone and must not move any task to remove an overload; the overload is only shown ([DD-029](DD-029-overloads-and-cross-project-conflicts-are-shown-in.md)).

It serves [UC-002](UC-002-reschedule-work-in-a-project.md), [UC-003](UC-003-assign-people-to-a-task.md) and [UC-006](UC-006-resolve-a-cross-project-red-flag.md).
