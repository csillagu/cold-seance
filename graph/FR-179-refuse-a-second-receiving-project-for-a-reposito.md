# FR-179: Refuse a second receiving project for a repository

While a repository has a receiving project ([FR-143](FR-143-mark-one-receiving-project-for-each-repository.md)), the system must refuse to mark another project as its receiving project, and leave the current one in place ([SRC-216](SRC-216-a-second-receiving-project-is-refused-until-the-f.md)).

It serves [UC-025](UC-025-manage-a-project-s-members.md).
