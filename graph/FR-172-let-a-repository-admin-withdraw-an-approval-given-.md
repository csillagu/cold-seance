# FR-172: Let a repository admin withdraw an approval given to a project

The system must accept from any admin of a repository the withdrawal of an approval given earlier for adding the repository to a project, and record the project as no longer approved for the repository ([SRC-185](SRC-185-a-repository-admin-can-reject-a-project-s-request-.md)).

It serves [UC-037](UC-037-withdraw-a-project-s-approval-for-a-repository.md).
