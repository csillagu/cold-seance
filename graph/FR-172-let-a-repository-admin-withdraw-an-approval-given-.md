# FR-172: Let a repository admin withdraw an approval given to a project

The system must let any admin of a repository withdraw an approval given earlier for adding the repository to a project ([SRC-185](SRC-185-a-repository-admin-can-reject-a-project-s-request-.md)).

Not stated: what happens to the project's tasks from the repository, and to the repository's link to the project, once the approval is withdrawn.

It serves [UC-037](UC-037-withdraw-a-project-s-approval-for-a-repository.md).
