# FR-172: Let a repository admin withdraw an approval given to a project

The system must let any admin of a repository withdraw an approval given earlier for adding the repository to a project, and must then stop the project pulling issues from the repository ([SRC-185](SRC-185-a-repository-admin-can-reject-a-project-s-request-.md), [SRC-169](SRC-169-a-project-sets-which-repositories-it-pulls-issues.md)).

It serves [UC-037](UC-037-withdraw-a-project-s-approval-for-a-repository.md).

Origin: composed by Claude from the items linked above, for issue #7. After its quality review for issue #11, keeping the project's tasks was split off into FR-178, and the receiving-project case left to FR-157. The wording is Claude's, not the stakeholder's; every obligation rests on a linked item.
