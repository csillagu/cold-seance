# FR-172: Let a repository admin withdraw an approval given to a project

The system must let any admin of a repository withdraw an approval given earlier for adding the repository to a project, and must then stop the project pulling issues from the repository ([SRC-185](SRC-185-a-repository-admin-can-reject-a-project-s-request-.md), [SRC-169](SRC-169-a-project-sets-which-repositories-it-pulls-issues.md)). That the project keeps the tasks it already has from the repository is the drafting agent's reading of SRC-185, not yet confirmed.

Not stated: what happens when the project is the repository's receiving project ([SRC-177](SRC-177-one-receiving-project-per-repository-gets-its-new.md)).

It serves [UC-037](UC-037-withdraw-a-project-s-approval-for-a-repository.md).
