# SRC-143: Who can add a project to a group

Everyone can add a new project to a group ([SRC-139](SRC-139-project-access-also-comes-through-groups.md)). An existing project can be added to a group only by that project's admin ([SRC-093](SRC-093-admin-role.md)).
