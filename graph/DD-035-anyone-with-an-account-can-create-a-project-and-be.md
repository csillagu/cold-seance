# DD-035: Anyone with an account can create a project and becomes its admin

## Decision

Anyone with an account can create a project, and becomes its admin.

## Alternatives considered

Only a system admin creates projects (the drafting agent's question), versus anyone with access to the system.

## Trade-offs

Gives up restricting project creation to system admins.

## Serves

This decision serves [SRC-093](SRC-093-admin-role.md), [SRC-097](SRC-097-no-self-registration-a-system-admin-creates-accoun.md).

Origin: as received, "projects can be created by anyone having access to the system". "Becomes its admin" is the drafting agent's addition and was not discussed.
