# SRC-151: A linked issue deleted on GitHub counts as closed

A linked issue deleted on GitHub is treated as if it had been closed ([SRC-060](SRC-060-finish-from-github-close-issue.md), [DD-032](DD-032-github-status-changes-that-break-a-constraint-are.md)).

As received, asked what the tool does when a linked issue is deleted on GitHub: "delete is like closed."
