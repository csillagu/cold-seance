# FR-088: Create a task's GitHub issue once it is assigned to a repository

Once a task is assigned to a repository, the system must create the task's GitHub issue in that repository; a task not assigned to a repository has no issue ([SRC-168](SRC-168-a-task-gets-its-github-issue-once-it-is-assigned-t.md), [SRC-066](SRC-066-tasks-planned-in-the-tool-create-their-github-issu.md)).

It serves [UC-001](UC-001-plan-a-task-in-a-project.md) and [UC-008](UC-008-work-on-an-issue-from-github.md).
