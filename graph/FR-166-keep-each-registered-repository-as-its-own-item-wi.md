# FR-166: Keep each registered repository as its own item with its admins

The system must keep each registered GitHub repository as an item of its own, separate from the projects that use it, with the people who are its admins ([SRC-180](SRC-180-repositories-are-their-own-item-in-the-tool-with-a.md)).

It serves [UC-033](UC-033-register-a-repository.md), [UC-034](UC-034-approve-adding-a-repository-to-a-project.md) and [UC-035](UC-035-change-a-repository-s-admins.md).
