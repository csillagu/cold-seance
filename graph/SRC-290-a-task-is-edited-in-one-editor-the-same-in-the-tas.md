# SRC-290: A task is edited in one editor, the same in the task dialog and on the task page

The task dialog, opened from the Kanban and the Gantt, and the task page show the same editor: the same fields, the task's status among them, saved with one Save for every field. Adding or removing a blocker or a subtask still takes effect at once.

As received, in the design session of 2026-11-23, recorded in issue #256 (the UI/UX review of the demo deployment). Asked, about items 30, 31 and 33 ("Status can be changed in three different ways, and the task page has none", "The task page has six separate save buttons", "The task dialog and the task page differ in fields and controls"), "How should task editing work?", with the options "One editor, two places" ("Dialog and page show the same editor: same fields, status included, one Save for every field. Adding or removing a blocker or subtask still takes effect at once."), "Page is the editor" and "Align fields only", the owner chose "One editor, two places".

Not stated: whether the Kanban keeps changing status by drag and drop beside the editor.
