# SRC-200: The tool can use an external hosted PostgreSQL such as Neon

The tool can be pointed at an external, hosted PostgreSQL database, such as Neon, instead of the one it is installed with.

As received, after the deployment was settled as the application next to PostgreSQL (DD-040): "Can it this way be pointed to an external datavase like neodb?" Claude read "neodb" as Neon, the hosted PostgreSQL service, and asked whether working with hosted PostgreSQL like Neon should be recorded as a requirement; the stakeholder answered: "3 yes".
