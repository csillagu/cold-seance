# FR-102: Seed a project from one or more GitHub repositories

The system must import into a project the issues of one or more existing GitHub repositories, with their sub-issue and blocked-by relations, their assignees, and their status from the Projects status field ([SRC-074](SRC-074-a-project-can-be-seeded-from-existing-github-repos.md)), from repositories whose admin has given the tool access ([SRC-099](SRC-099-the-github-app-is-installed-per-repo-by-the-repo-s.md)).

It serves [UC-010](UC-010-seed-a-project-from-github-repositories.md).
