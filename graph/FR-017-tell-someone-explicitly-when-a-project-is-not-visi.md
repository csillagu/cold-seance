# FR-017: Tell someone explicitly when a project is not visible to them

When a project is not visible to someone, the system must tell them explicitly that the project is not visible to them, not a vague message such as "not found or deleted or no permission" ([SRC-119](SRC-119-a-project-someone-cannot-see-is-reported-as-not-vi.md)).

It serves [UC-005](UC-005-depend-on-another-project-s-milestone.md).
