# SRC-163: For an assignee without a calendar, the global calendar stands in for that person only

When an assigned person has not filled in their own calendar ([SRC-125](SRC-125-a-task-with-no-assignees-takes-its-forbidden-dates.md)), the global calendar stands in for that person only; the other assigned people's own calendars still apply ([SRC-124](SRC-124-forbidden-dates-come-from-the-assignees-calendars.md)).

As received, asked whether the global calendar then replaces only the missing person's days off or the whole task's: "Missing persons only of course."
