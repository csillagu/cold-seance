# SRC-150: A person's GitHub account is linked by the person or a system admin

The link between a person's account in the tool and their GitHub account ([SRC-071](SRC-071-people-without-a-github-account-get-issues-without.md)) is set by the person themselves or by a system admin ([SRC-097](SRC-097-no-self-registration-a-system-admin-creates-accoun.md)).

As received, asked how a person's account in the tool is linked to their GitHub account: "person or global admin sets it". "Global admin" is read as system admin, the term used in SRC-128 for the people who create accounts.
