# DD-001: The plan is stored in the tool's own backend, not in GitHub issues

## Decision

The plan is stored in the tool's own backend instead of in GitHub issues.

## Alternatives considered

The tool's own backend, versus a GitHub App working directly on the GitHub issues.

## Trade-offs

Gives up having a GitHub App work directly on the issues.
