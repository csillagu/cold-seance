# SRC-225: A project search matches part of the name, ignoring case

A search in the header's project search bar ([SRC-220](SRC-220-the-header-holds-a-project-search-bar.md)) matches on the project's name: part of the name is enough, and upper and lower case are not told apart.

As received, in the design session of 2026-11-03, asked what a project search matches on: "name".

As received, in the same session, asked whether the match is partial and whether it ignores case: "partial, ignore case".

Split by Claude at the owner's request in the same session ("2 yes"), after the quality review found the earlier item bundled.
