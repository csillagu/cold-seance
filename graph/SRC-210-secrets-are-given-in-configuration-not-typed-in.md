# SRC-210: Secrets are given in configuration, not typed in by an admin

Secrets such as the GitHub Apps' private keys are not typed into the tool by an admin. They are given in configuration: a YAML file or environment variables.

As received, in the design session of 2026-11-03: "Anither thing: this admin typing secrets by hand is not a good thing to do, i propose its done in a config yml environmental variable. Alomg with poll intervall etc etc. what do you say?"

Asked whether this item should stay verified although the owner put it as a proposal, the owner answered later in the same session: "Src 210 can stay verified, double checked it." The owner confirmed configuration in the same answer: "config confirmed".
