# FR-200: Reject an assignment that names a person twice

The system must reject an assignment that names the same person more than once, and store nothing of it ([SRC-239](SRC-239-a-person-cannot-be-assigned-to-a-task-twice.md), [SRC-032](SRC-032-assignment-is-a-concrete-list-of-people.md)).

It serves [UC-003](UC-003-assign-people-to-a-task.md).
