# SRC-192: Every new GitHub issue becomes a task, whoever opened it

Every new issue opened in a repository a project pulls issues from (SRC-169) becomes an unscheduled task in that project, whoever opened it and whatever it is about.

As received, asked which new GitHub issues become tasks, given the earlier wording "by a third party or for a non-plannable item such as a bug": "all new issues become tasks". On who opens them: "does not matter WHO changed the issue (or creates one) the point it that it changes."

This replaces SRC-061 and SRC-115, which covered only issues opened by third parties and issues for non-plannable items such as bugs. Their source statement, from the design session of 2026-10-31, was: "GH issues are only created directly by third parties, or non plannable things, like bugs etc".
