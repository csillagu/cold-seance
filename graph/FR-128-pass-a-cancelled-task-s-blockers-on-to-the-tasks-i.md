# FR-128: Pass a cancelled task's blockers on to the tasks it blocked

When a task is cancelled, the system must make each task it blocked blocked by whatever the cancelled task was blocked by ([SRC-159](SRC-159-what-cancelling-a-task-does.md)).

It serves [UC-022](UC-022-cancel-a-task.md).
