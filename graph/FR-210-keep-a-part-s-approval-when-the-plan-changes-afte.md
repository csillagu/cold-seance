# FR-210: Keep a part's approval when the plan changes afterwards

For a proposal that spans several projects, the system must keep each part's approval when the plan changes after it was given, withdraw every approval when the proposal is edited, and check the plan only against the preview seen by the approver of the part being approved ([SRC-256](SRC-256-a-part-s-approval-stands-when-the-plan-changes-a.md), [DD-025](DD-025-a-proposal-may-span-several-projects-each-project.md)).

It serves [UC-012](UC-012-review-and-approve-an-ai-proposal.md).
