# FR-053: Make everything shown in a view editable there unless noted

The system must let a user edit, in the view where it is shown, everything that view shows, except where an item says otherwise ([SRC-113](SRC-113-everything-shown-in-a-view-is-editable-there-unles.md)), within what the user's role allows ([SRC-091](SRC-091-read-only-role.md), [SRC-136](SRC-136-contributor-role.md), [SRC-092](SRC-092-read-write-role.md)).

It serves [UC-001](UC-001-plan-a-task-in-a-project.md), [UC-002](UC-002-reschedule-work-in-a-project.md), [UC-007](UC-007-track-task-status-in-the-tool.md) and [UC-021](UC-021-link-tasks-with-constraints.md).
