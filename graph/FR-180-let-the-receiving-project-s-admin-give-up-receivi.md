# FR-180: Let the receiving project's admin give up receiving

The system must let a repository's receiving project give up that role, after which the repository has no receiving project until a project is marked again ([SRC-216](SRC-216-a-second-receiving-project-is-refused-until-the-f.md)). Claude reads this as done by the admin of the receiving project, who marked it ([SRC-178](SRC-178-the-receiving-project-is-marked-by-a-project-admin.md)); who gives it up is not stated.

It serves [UC-025](UC-025-manage-a-project-s-members.md).

Origin: composed by Claude from the items linked above, for issue #11, from SRC-216: a second receiving project is refused until the first gives the role up. That the admin of the receiving project gives it up is Claude's reading, since that admin marked it (SRC-178). The wording is Claude's, not the stakeholder's; every obligation rests on a linked item.
