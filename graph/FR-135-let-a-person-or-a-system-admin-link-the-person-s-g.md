# FR-135: Let a person or a system admin link the person's GitHub account

The system must let a person, or a system admin, link the person's account in the tool to their GitHub account ([SRC-150](SRC-150-a-person-s-github-account-is-linked-by-the-person.md)), given by the GitHub account's name ([SRC-202](SRC-202-a-person-s-github-account-is-identified-by-its-nam.md)).

It serves [UC-003](UC-003-assign-people-to-a-task.md).

Origin: composed by Claude from the items linked above, for issue #5; identifying the GitHub account by its name was added for issue #11 from SRC-202. The wording is Claude's, not the stakeholder's; every obligation rests on a linked item.
