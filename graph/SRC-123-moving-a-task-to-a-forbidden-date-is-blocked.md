# SRC-123: Moving a task to a forbidden date is blocked

Moving any task to a forbidden date ([SRC-124](SRC-124-forbidden-dates-come-from-the-assignees-calendars.md), [SRC-125](SRC-125-a-task-with-no-assignees-takes-its-forbidden-dates.md), [SRC-126](SRC-126-company-holidays-are-forbidden-for-every-task.md)) is blocked, through the UI, the REST API and the MCP server alike.

As received: "So the ui should block pulling any task to a forbidden date." Asked whether this holds only for the UI or also for the REST API and MCP: "yes all 3, ui was just an example".
