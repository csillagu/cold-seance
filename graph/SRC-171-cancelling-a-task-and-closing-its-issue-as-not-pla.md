# SRC-171: Cancelling a task and closing its issue as not planned go together

Cancelling a task in the tool closes its GitHub issue as "not planned". Closing a task's issue as "not planned" on GitHub cancels the task in the tool.

As received, told that cancelling closes the issue as "not planned" while an issue closed as "not planned" on GitHub was reopened (DD-017): "okay, this is not good. Lets reweite thay fr096. Canceling in the tool closes issue as not planned. Closing the issue as not planned cancels it in the tool."

This replaces DD-017, under which an issue closed as "not planned" was reopened and tasks could be cancelled only in the tool.
