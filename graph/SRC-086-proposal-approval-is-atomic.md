# SRC-086: Proposal approval is atomic

Approving a proposal applies its changes in one transaction against the plan version the reviewer saw. If the plan changed in between, the preview refreshes and the reviewer confirms again.

Origin: the drafting agent's; present in both versions of the proposal flow and never contested.
