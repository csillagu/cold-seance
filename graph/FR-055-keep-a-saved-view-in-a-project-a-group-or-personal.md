# FR-055: Keep a saved view in a project, a group or personally

The system must keep each saved view in one place: a project, where anyone who can read the project sees it; a group, where the group's members see it; or personally, where only its owner sees it ([SRC-111](SRC-111-views-are-kept-in-a-project-a-group-or-personally.md)).

It serves [UC-014](UC-014-create-a-saved-view.md) and [UC-018](UC-018-create-a-group-and-give-it-access-to-projects.md).
