# FR-198: Keep people who lose read access in a task's eligibility and assignment

The system must keep a person in a task's eligibility expression and assignment when they lose read access to the task's project after being written there, and must let them be removed from either ([SRC-238](SRC-238-people-who-lose-read-access-stay-on-a-task-marked.md)). Adding them again while they cannot read the project stays rejected ([FR-031](FR-031-reject-eligibility-or-assignment-for-someone-witho.md)).

It serves [UC-003](UC-003-assign-people-to-a-task.md).
