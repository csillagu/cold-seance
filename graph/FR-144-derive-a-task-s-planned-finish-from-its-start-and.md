# FR-144: Derive a task's planned finish from its start and duration

The system must derive a task's planned finish from its planned start and its duration, counted over the task's working days ([SRC-023](SRC-023-minimum-task-fields.md), [SRC-121](SRC-121-scheduling-skips-non-working-days.md)).

It serves [UC-001](UC-001-plan-a-task-in-a-project.md) and [UC-002](UC-002-reschedule-work-in-a-project.md).
