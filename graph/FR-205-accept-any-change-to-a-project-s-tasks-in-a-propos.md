# FR-205: Accept any change to a project's tasks in a proposal

The system must accept in a proposal any change that can be made to a project's tasks in the live plan: creating a task; changing its fields, its parent or its blockers; setting its status; assigning it to a repository; or cancelling it ([SRC-247](SRC-247-a-proposal-can-change-anything-in-a-project-s-pla.md)).

It serves [UC-011](UC-011-an-ai-agent-proposes-a-plan-change.md).
