# SRC-183: System admins can change a repository's admins

A system admin can change who the admins of a repository are in the tool ([SRC-180](SRC-180-repositories-are-their-own-item-in-the-tool-with-a.md)). This is the safeguard against the wrong person registering a repository first ([SRC-182](SRC-182-anyone-can-register-an-unregistered-repository-and.md)).

As received: "sys admins can change repository admins (in the tool) so nothing bad can happen."

Not stated: whether a repository's own admins can add or remove admins; whether a repository can be left with no admin.
