# SRC-048: Shared milestones: one owning project, others can depend on it, dependents turn red

A milestone belongs to one owning project. Other projects can depend on it (blocked by). If it moves past a dependent task's start, the dependency turns red in the dependent project, and the dependent task's dates do not move.

The stakeholder's want, as received: "shared milestones". The owning-project structure is the drafting agent's proposal.
