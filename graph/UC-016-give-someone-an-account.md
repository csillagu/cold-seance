# UC-016: Give someone an account

## Goal

Let a new person use the tool.

## Steps

1. The system admin creates a local account for the person ([SRC-097](SRC-097-no-self-registration-a-system-admin-creates-accoun.md), [DD-027](DD-027-local-accounts-only-for-now.md)).

## Success criteria

- The person can sign in with the new account.

## Failure modes

- Nobody can create their own account: there is no self-registration ([SRC-097](SRC-097-no-self-registration-a-system-admin-creates-accoun.md)).
