# FR-164: Log both channels for a change from an approved AI proposal

For each change an approved AI proposal applies, the system must record both channels in the audit log: the MCP server, through which the AI created the proposal, and the UI, through which it was approved ([SRC-173](SRC-173-a-change-from-an-approved-ai-proposal-is-logged-wi.md), [SRC-095](SRC-095-every-change-is-recorded-in-an-audit-log.md)).

It serves [UC-012](UC-012-review-and-approve-an-ai-proposal.md).
