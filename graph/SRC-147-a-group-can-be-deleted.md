# SRC-147: A group can be deleted

A group ([SRC-139](SRC-139-project-access-also-comes-through-groups.md)) can be deleted, only by a system admin ([SRC-097](SRC-097-no-self-registration-a-system-admin-creates-accoun.md)). The group's saved views ([SRC-111](SRC-111-views-are-kept-in-a-project-a-group-or-personally.md)) disappear with it.

As received, asked whether a group can be deleted: "yes". Asked who can delete a group, only its admins or someone else: "System admin". That no one else can delete it was the drafting agent's reading of that answer; asked to confirm, the stakeholder said: "yes only system admin". Asked what happens to the group's saved views: "Disappear".
