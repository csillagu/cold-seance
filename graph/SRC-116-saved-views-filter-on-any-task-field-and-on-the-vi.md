# SRC-116: Saved views filter on any task field and on the viewer

A saved view ([SRC-108](SRC-108-kanban-and-gantt-support-saved-views.md)) can filter on any task field: "any task field I would say."

A filter can also refer to the person viewing the view (`@me`), as in "MY kanban". This works wherever a view is kept ([SRC-111](SRC-111-views-are-kept-in-a-project-a-group-or-personally.md)), group views included: "group views needs to work with @me too".
