# SRC-245: Only a project's read-write members and admins create proposals for it

Only a project's read-write members and admins can create a proposal that changes the project.

As received, in the design session of 2026-11-06, in the work on the proposal store (SC-010, issue #114). Claude reported that the items say who reviews, edits and approves a proposal, but not who may create one, and offered three options: any role in the project, read-only included; contributor and above; or read-write and admin only. The owner answered: "Write and admin only".
