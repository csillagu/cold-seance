# SRC-074: A project can be seeded from existing GitHub repos

A project can be seeded from one or more existing repos. The import brings in issues with their sub-issue and blocked-by relations, assignees, and status from the Projects status field.

As received: "GH import (or seeding the thing from GH) IS needed".
