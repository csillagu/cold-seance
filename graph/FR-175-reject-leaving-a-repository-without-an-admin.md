# FR-175: Reject leaving a repository without an admin

The system must reject any change that would leave a registered repository without an admin, including a change made by a system admin ([SRC-188](SRC-188-a-repository-cannot-be-left-without-an-admin.md), [SRC-183](SRC-183-system-admins-can-change-a-repository-s-admins.md)).

It serves [UC-035](UC-035-change-a-repository-s-admins.md) and [UC-039](UC-039-remove-an-admin-from-a-repository.md).
