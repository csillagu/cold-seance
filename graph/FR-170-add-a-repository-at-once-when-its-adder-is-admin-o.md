# FR-170: Add a repository at once when its adder is admin of both it and the project

When the person adding a repository to a project is an admin of both the repository and the project, the system must add it without a separate approval ([SRC-184](SRC-184-an-admin-of-both-the-repository-and-the-project-ad.md)).

It serves [UC-010](UC-010-seed-a-project-from-github-repositories.md).
