# SRC-256: A part's approval stands when the plan changes afterwards

In a proposal over several projects, each part is checked against the plan its approver saw when approving, and the changes apply at the last part's approval, against the plan that approver saw. An earlier part's approval stands if the plan changes afterwards; only an edit of the proposal withdraws the approvals given.

As received, in the design session of 2026-11-15, on issue #130 (the proposal approval, SC-048). Asked "Alice approves the Apollo part of a two-project proposal. Later the plan changes, and then bob approves the Borealis part. What happens to alice's approval?", with the options "It stands: each part is checked against the plan its approver saw when they approved, and the changes apply at bob's approval, against the plan bob saw; only an edit of the proposal itself withdraws approvals", "Withdrawn if its project changed" and "Withdrawn on any change", the owner chose: "It stands".
