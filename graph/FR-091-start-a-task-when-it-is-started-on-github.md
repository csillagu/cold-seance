# FR-091: Start a task when it is started on GitHub

When a task's issue is started on GitHub, through the Projects status field ([DD-015](DD-015-start-and-hold-come-from-the-github-projects-statu.md)), the system must set the task to in progress and record its actual start ([SRC-058](SRC-058-start-from-github.md)).

It serves [UC-008](UC-008-work-on-an-issue-from-github.md).
