# SRC-087: Stale proposal fallback: reject and ask for a new one

If the preview no longer makes sense, the reviewer rejects the proposal and asks the AI for a new one. Nothing is rebased automatically beyond the live preview.

Origin: part of the drafting agent's revision of the proposal flow; not weighed against an alternative.
