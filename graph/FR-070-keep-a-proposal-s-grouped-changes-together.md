# FR-070: Keep a proposal's grouped changes together

The system must keep the changes a proposal groups together as one group, which is kept, edited or dropped as one ([DD-023](DD-023-proposal-changes-are-grouped.md)).

It serves [UC-011](UC-011-an-ai-agent-proposes-a-plan-change.md) and [UC-012](UC-012-review-and-approve-an-ai-proposal.md).
